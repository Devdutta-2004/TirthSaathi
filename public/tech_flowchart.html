ARCHITECTURE SPEC v2.4 Live ML Mesh

TirthSaathi — End-to-End System & ML Tech Flow

Closed-Loop Machine Learning, Real-Time P2P Mesh & Biometric Vision Architecture

TirthSaathi ingests 40-year longitudinal pilgrimage footfall records, historical diurnal arrival curves, and live QR gate reservations into a continuous online learning ML engine. It dynamically re-routes devotees before stampede bottlenecks form, tracks family circles via WebRTC/UWB mesh, and connects to 14,000+ checkpoint CCTV embeddings for biometric facial identification.

6-Stage Deep Dive: Tech Stack & API Matrix
STAGE 01

Historical Data & Macro ML Training

Ingests 40-year ground truth footfall dataset (1986–2026) alongside diurnal 24-hr Gaussian probability curves for Aarti influx peaks.

Languages: Python 3.11, JavaScript (ESM)
APIs & Libs: NumPy, Pandas, Scikit-Learn, IndexedDB
Key File: src/data/historicalCrowdData.js
STAGE 02

QR E-Pass & Family Slot Booking

Devotees reserve time slots and link family members into encrypted mesh nodes. Generates tamper-proof QR tokens with HMAC-SHA256 signatures.

Languages: JavaScript (React 19), SQL
APIs & Libs: Canvas API, Web Crypto API, Supabase REST
Key File: src/services/passService.js
STAGE 03

P2P Mesh & UWB Precision Radar

Decentralized peer-to-peer tracking using WebRTC. Hardware GPS, compass azimuth, battery telemetry, and synthesized acoustic chime beacons.

Languages: JavaScript (Browser Hardware APIs)
APIs & Libs: Geolocation API, Web Audio, PeerJS, Leaflet
Key File: src/services/geoService.js
STAGE 04

Live Influx, Wait Times & AI Routing

Calculates gate occupancy rates and waiting times via Little's Law. Proactively prompts devotees to less crowded gates before bottlenecks form.

Languages: Node.js v20, JavaScript
APIs & Libs: WebSocket (ws), React Context API
Key File: src/services/crowdEngine.js
STAGE 05

Daily Scans & Online Learning Loop

Physical turnstile scans log discrepancies between actual vs predicted counts. Daily SGD online learning re-tunes gate bias weights continuously.

Languages: Node.js, Python FastAPI, SQL
APIs & Libs: Service Worker Cache, SGD Regressor, Supabase
Key File: src/services/crowdEngine.js
STAGE 06

PunarMilan AI Facial Biometrics

Locates lost members in crowds by extracting 68 facial landmarks & 128-d vector embeddings, matched via cosine similarity against 14,000+ CCTV nodes.

Languages: JavaScript (WebGL), Python
APIs & Libs: @vladmandic/face-api, pgvector, AWS S3 / R2 SDK
Key File: src/services/aiFaceEngine.js
Core Mathematical & Algorithmic Models
1. Little's Law (Wait Time)

$$W_g(t) = \frac{N_g(t) + \lambda_{\text{booked}}(t)}{\mu_g(t)}$$

Where \(N_g\) is in-bounds count, \(\lambda\) is upcoming booked influx, and \(\mu_g\) is turnstile clearance rate per minute.

2. Facial Vector Cosine Similarity

$$\text{Sim}(A, B) = \frac{A \cdot B}{\|A\|_2 \|B\|_2} \ge 0.88$$

Calculates 128-dimensional euclidean angular similarity between missing person photo and CCTV frame embeddings.

3. Online SGD Continuous Learning

$$w(t+1) = w(t) - \eta \nabla \mathcal{L}(\epsilon(t))$$

Where \(\epsilon(t) = \text{Actual Influx} - \text{Predicted Influx}\), dynamically tuning daily gate bias weights.
